# Chapter 09 1차원 배열

## 학습 목표

- 1차원 배열을 선언·초기화하고 인덱스로 읽고 쓴다.
- 유효 인덱스 범위와 범위를 넘는 위험을 이해한다.
- `for`로 배열을 순회해 합·평균·최댓값을 구한다.
- `char` 배열과 널 문자 `\0`으로 끝나는 문자열 기본을 익힌다.

## 본문

### 09-1 배열 선언과 초기화

**배열**은 같은 타입 값을 메모리에 연속된 칸으로 모아 두는 방법입니다. 크기를 정해 만들 때는 `int nums[5];`처럼 씁니다. 여기서 `5`는 칸 개수입니다. 처음부터 값을 넣으려면 `int nums[5] = {10, 20, 30, 40, 50};`처럼 **초기화 목록**을 쓸 수 있습니다. 목록만 두고 크기를 생략하면 `int nums[] = {10, 20, 30};`처럼 컴파일러가 칸 수를 맞춥니다.

아래를 실행해 첫 칸과 마지막 칸이 어떻게 나오는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int nums[5] = {10, 20, 30, 40, 50};

    printf("%d\n", nums[0]);
    printf("%d\n", nums[4]);
    return 0;
}
```

**예상 출력**

```text
10
50
```

**코드 해석**

- `nums[5]`는 정수 칸 5개를 만듭니다.
- `nums[0]`은 첫 값 `10`, `nums[4]`는 마지막 값 `50`입니다.
- 초기화 목록으로 값을 한꺼번에 넣었습니다.

### 09-2 인덱스와 범위

**인덱스**는 각 칸의 위치 번호이며 **0부터** 시작합니다. 칸이 5개이면 유효 인덱스는 `0`부터 `4`까지입니다. 마지막 인덱스는 항상 **크기 - 1**입니다. 이 범위를 넘는 `nums[5]` 같은 접근은 컴파일러가 꼭 막아 주지 않으며, 실행 중 잘못된 메모리를 건드려 **정의되지 않은 동작**이 될 수 있습니다. 인덱스는 반복문 조건과 함께 엄격히 맞춥니다.

| 용어 | 의미 |
|---|---|
| 인덱스 | 배열에서 각 원소의 위치 번호. 0부터 시작 |
| 유효 범위 | 크기 `N`일 때 `0`부터 `N - 1`까지 |
| 정의되지 않은 동작 | 표준이 결과를 보장하지 않는 위험한 실행 |

아래를 실행해 인덱스와 값이 함께 나오는지 확인해 보세요. 주석 처리된 `nums[5]`는 켜지 마세요. 범위 밖 접근의 위험만 알아 둡니다.

```c
#include <stdio.h>

int main(void)
{
    int nums[5] = {10, 20, 30, 40, 50};
    int i;

    for (i = 0; i < 5; i++)
    {
        printf("%d: %d\n", i, nums[i]);
    }
    /* printf("%d\n", nums[5]); */ /* 크기 5 → 인덱스 5는 범위 밖 */
    return 0;
}
```

**예상 출력**

```text
0: 10
1: 20
2: 30
3: 40
4: 50
```

**코드 해석**

- `i`는 `0`부터 `4`까지입니다. 조건은 `i < 5`입니다.
- `nums[i]`로 인덱스와 값을 함께 다룹니다.
- `nums[5]`는 유효 범위가 아닙니다.

### 09-3 순회와 집계

배열의 모든 칸을 살펴보는 것을 **순회**라고 합니다. 칸 개수와 인덱스가 분명할 때는 **`for`**가 읽기 쉽습니다. 합·평균·최댓값처럼 전체를 한 번씩 보는 작업은 순회의 전형적인 쓰임입니다. 평균은 정수끼리만 나누면 소수 아래가 잘리므로, `(double)합 / 개수`처럼 **실수 나눗셈**이 되게 맞춥니다.

아래를 실행해 합과 평균이 나오는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int nums[4] = {80, 95, 70, 100};
    int i;
    int sum = 0;

    for (i = 0; i < 4; i++)
    {
        sum += nums[i];
    }

    printf("%d\n", sum);
    printf("%.2f\n", (double)sum / 4);
    return 0;
}
```

**예상 출력**

```text
345
86.25
```

**코드 해석**

- `for`로 네 칸을 돌며 `sum`에 더합니다.
- `(double)sum / 4`로 실수 나눗셈을 유지해 평균을 구합니다.
- `%.2f`는 소수 둘째 자리까지 출력합니다.

### 09-4 `char` 배열과 문자열

C에서 흔히 말하는 **문자열**은 `char` 배열이며, 끝에는 **널 문자** `\0`이 들어갑니다. `\0`은 “여기까지가 문자열”이라는 표시입니다. `printf("%s", ...)`는 `\0`을 만날 때까지를 한 덩어리로 출력합니다. 배열 크기는 글자 수보다 **최소 1칸 더** 잡아 `\0` 자리를 남깁니다. 예로 `char name[4] = "Kim";`은 `K`, `i`, `m`, `\0` 네 칸을 씁니다.

| 항목 | 정수 배열 | 문자 배열 문자열 |
|---|---|---|
| 타입 | `int` | `char` |
| 끝 표시 | 없음 | `\0` 있음 |
| 출력 | 반복문으로 칸마다 | `%s`로 한 번에 가능 |

아래를 실행해 문자열 출력과, `\0`까지 세는 길이가 맞는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    char name[10] = "Kim";
    int len = 0;

    printf("%s\n", name);

    while (name[len] != '\0')
    {
        len++;
    }
    printf("%d\n", len);
    return 0;
}
```

**예상 출력**

```text
Kim
3
```

**코드 해석**

- `name`은 `"Kim"`으로 초기화되며 끝에 `\0`이 붙습니다.
- `%s`는 `\0` 직전까지 출력합니다.
- `name[len] != '\0'`인 동안만 `len`을 올려 글자 수를 셉니다. 라이브러리 길이 함수 없이도 됩니다.

### 연습문제

**문제 1**
- 문제: 정수 배열에서 최댓값을 출력하세요.
- 입력: 없음. 코드에 `{3, 9, 2, 7}`처럼 배열을 두고 시작해도 됩니다.
- 출력: `9`
- 조건: 반복문으로 직접 비교. 라이브러리 최댓값 함수 사용 금지

**문제 2**
- 문제: 정수 다섯 개의 평균을 소수 둘째 자리까지 출력하세요.
- 입력: 정수 5개. 예: `10 20 30 40 50`
- 출력: `30.00`
- 조건: 배열에 저장한 뒤 `(double)합 / 5`로 실수 나눗셈

**문제 3**
- 문제: 배열의 각 칸을 `인덱스: 값` 형태로 한 줄씩 출력하세요.
- 입력: 없음. 예 배열은 `{10, 20, 30}`
- 출력:
  ```text
  0: 10
  1: 20
  2: 30
  ```
- 조건: `for`와 배열 크기 `3` 사용

**문제 4**
- 문제: 공백 없는 문자열 하나를 배열에 넣고, `\0`까지 세어 길이를 출력하세요.
- 입력: 없음. 예로 `char word[20] = "hello";`를 사용해도 됩니다.
- 출력: `5`
- 조건: `while` 또는 `for`로 `\0` 전까지 직접 세기. `string.h` 함수 사용 금지

### 정답 포인트

- 문제 1: `max`를 첫 원소로 두고 `for`로 더 큰 값이면 갱신
